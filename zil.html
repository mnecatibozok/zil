📋 System Manifest
Bell System — Developer Reference Document · Maintained by Claude (Anthropic)
🏗 System Architecture — Overview
▸ Layers and how the components relate
① HARDWARE LAYER
Arduino Uno (anfi2.ino) — Connected to the browser over USB/serial port. Bidirectional: the browser sends ANFI_AC/ANFI_KAP/DURUM, and the Arduino replies with OK:/DURUM:/BUTON:/MARS:/ZIL:/ANFI:/DUR: messages. 9600 baud, line-based protocol.
Arduino → D7 relay → 220V amplifier. D11/D12 LEDs. D2/D3/D5/D6 433MHz RF receiver. D4 manual button.
Sound system (PC/laptop) — Web Audio API. playSnd() → HTML Audio object → sound card → speaker → amplifier. The output audio channel is selected via setSinkId().
② PYTHON SERVER LAYER (zunucu/)
sunucu.py — HTTP server, localhost:PORT. Writes the port to zil-port.txt on startup. Generates ses-manifest.json and mp3-manifest.json (scans the zilsesleri/ folder).
handler.py — All /api/ routes. HTML → server direction: prayer times, announcement config read/save, blacklist, RF remote command polling, safe shutdown.
ezan.py — Diyanet → diyanethaber.com.tr → Aladhan API chain. Returns daily prayer times to handler.py.
zilsesler.py — Reads/writes zil-anons-ayar.json and zil-ses-ayar.json. Python side of loadAnnouncementConfig / saveAnnouncementConfig / loadZilSesAyar / saveZilSesAyar. zil-ses-ayar.json stores which file is used for each SND_DEFS key — an empty string means the SND_DEFS default (zil.mp3).
app_settings.py — Server-side backup of key localStorage values, written to zil-ayarlar.json. On startup, init() fetches this file and restores it into localStorage before anything else loads, so settings survive even if the browser profile (e.g. a kiosk Chrome profile) is wiped. Whitelisted keys only — see ALLOWED_KEYS.
The server is NOT required — the HTML also works without file://localhost; drag-and-drop can be used to load sounds. The server is required for prayer time, announcement setting, and server-side settings-backup persistence.
③ HTML/JS MAIN APPLICATION (zil-programi.html)
All logic lives in a single file. ~9600+ lines. Sections are numbered §1–§25.
BELL ENGINE (§8): tick() [Layer 1, every 1s] → checkBells() → fire() → bellRing() chain. Three independent timers:
• Layer 1 — setInterval 1s. Second-precision early bells (teacher entry 30s early). fromSafetyTimer=true, does not change _lastUpdateMs.
• Layer 2 (Bombproof) — Synchronized setTimeout at the start of every minute. Updates _lastUpdateMs and triggers the catchup-gap calculation.
• Layer 3 — DOM-independent schedule scanner (setInterval). Prevents sleep (NoSleep.js-style logic) while a bell is coming up.
SOUND ENGINE (§7, §9):
• playSnd(key, cb) — Gets the URL from SND_DEFS, creates an HTML Audio object, plays it after applying setSinkId. Holds the curAudio reference.
• playAnnouncement(filename, cb) — Plays an announcement from _announcementUrls or a /zilsesleri/ URL. Shares the same curAudio pool as playSnd.
• playMp3Bell(cb) — Plays music instead of a bell sound when MP3 mode is on. Picks without repeats from the _mp3BellQueue queue.
• stopCurAudio() — Stops curAudio and sets it to null. Called before every new sound starts.
• SND_DEFS default files — The default file for zilTenefus, zilOgrenci, zilOgretmen, zilToplanma is now zil.mp3 (previously they were separate files like zil_tenefus.mp3 etc.). All of them play zil.mp3 until the user picks a different file with 📁.
• SND_FALLBACK_TO_BELL — ['bellBreak','bellStudent','bellTeacher','bellAssembly']. If autoFetchSounds() finds an empty entry or 'zil.mp3' in zil-ses-ayar.json for these keys, it sets sndUrls[k] = sndUrls['bell'] and marks def._isFallback=true. If an old custom file loaded from the manifest exists (zil_ogrenci.mp3 etc.) it gets reset and saved to the server as 'zil.mp3' — the old file does not come back after the app is closed and reopened. buildSndPanel() shows the file name in orange while in fallback state; it turns green and _isFallback=false once the user picks their own file with 📁.
• persistSndToServer(key, file, def) — Converts the sound file picked with 📁 to base64 and writes it to the zilsesleri/ folder via POST /api/sound-upload, then updates zil-ses-ayar.json with bellSoundConfigSave() — the file selection is saved instantly to both disk and JSON without needing the Save button. The selection is kept after the app is closed and reopened. Only effective while running on localhost/127.0.0.1.
SCHEDULE ENGINE (§4, §8+):
• schedules[di] — A 7-day array. Each entry is generated by buildSchedule/PlanB/PlanC. item.type: 'top'|'ders'|'ara'|'ogle'.
• Plan A — Fixed weekly schedule. Stored in localStorage as zilSistemiV10. Generated by buildSchedule(di).
• Plan B — Different break durations. zilPlanBSettings + zilPlanBTakvim. Automatic switching by calendar days or weekday.
• Plan C — Block lessons (group-based). zilPlanCSettings.gruplar: [{tip, adet, sure, ara, araSure}]. Each group is a block or a single lesson plus the break that follows it. buildSchedulePlanC processes the groups in order, producing lesson/break rows. Calendar management via zilPlanCTakvim.
• _dayPlans[di] — Which plan is active for that day. Can be changed instantly with the A/B/C button on each day tab.
AMPLIFIER SYSTEM (§ANFİ):
• Web Serial API — navigator.serial.requestPort(). VID/PID stored in localStorage, auto-connected on startup via ampAutoConnect(). First attempt at 500ms, then 5 total attempts at 1.5/3/6/10s intervals. If no VID/PID match is found and only one port is listed, that one is tried. An "already open" error is caught and the port is used directly. navigator.serial connect/disconnect events are listened for — reconnects automatically when the Arduino is unplugged and replugged. port.forget() is called on disconnect — clears the browser cache, avoiding the "dirty port" issue. The port is closed properly on beforeunload — prevents an "already open" error when the page is refreshed.
• ampPreBell() — Called before every bell. Sends ANFI_AC if the amplifier is off, waits {pre} seconds.
• ampPostBell() — Called after the bell + announcement finish. Waits {post} seconds, sends ANFI_KAP.
• _ampRetryStart() — 10s × 12 = 2min retry loop on disconnect. Stops via _ampRetryStop() once connected. Also triggered on a USB disconnect event.
PRAYER TIME SYSTEM (§22+):
• prayerConflictCheck() inside fire() — Called before every bell trigger. If there is a conflict the bell does not ring, and _fireTs is not locked (retried once the minute passes).
• prayerAutoFetch() — Fetches the day's prayer times once a day. Diyanet chain: server /api/prayer-times → ezan.py → external API.
• Tolerance — ±N minutes (configurable). Guards both before and after the prayer time.
ANNOUNCEMENT SYSTEM (§9, §11b):
• _announcementConfig — {tenefus, ogretmen, ogrenci, toplanma, sonZil} — which file is tied to which bell type.
• _announcementUrls — filename → verified URL map. Filled from ses-manifest.json by announcementManifestLoad().
• loadAnnouncementConfig() — Fetches from /api/announcement-config. On failure, falls back to the localStorage zilAnonsAyar backup and retries 3× at 5s intervals.
• Chain: bellRing() → zilSonraAnons(zilKey, anosTip) → playSnd(zilKey, cb) → cb: playAnnouncement(f, cbAnfi) → cbAnfi: ampPostBell().
• Bell sound keys (updated 06/16/2026): break end/last bell → zilTenefus, student entry → zilOgrenci, teacher entry → zilOgretmen, assembly → zilToplanma. The old 'bell' key remains only for the manual button/RF remote.
④ DATA FLOW — TIME → BELL
Layer1/2 setInterval
→ checkBells(ts, di, sched)
→ fire(key, fn, label, time, sndKey)
→ [prayer time check, is the sound loaded, _fireTs lock]
→ fn() i.e. bellRing(normalKey, anonsKey)
→ ampPreBell() [ANFI_AC + wait]
→ playSnd(zilTenefus/zilOgrenci/zilOgretmen/zilToplanma, cb) or playMp3Bell(cb)
→ cb: playAnnouncement(filename, cbAnfi) [optional]
→ cbAnfi: ampPostBell() [ANFI_KAP + wait]
⑤ RE-TRIGGER GUARD (_fireTs)
Once _fireTs[key] = true, that bell key won't ring again that day. Cleared at midnight by §16 Daily Reset. _fireTs is not locked on a prayer-time conflict — it can be retried once the minute passes. It is not locked if the sound isn't loaded yet — once the sound arrives, autoFetchSounds.then() calls checkBells again.
📁 File Structure
zil-programi.html — Main application (~9600+ lines). All UI, the scheduler, Web Serial, the sound engine, plan management, and prayer-time checks live in this file.
zunucu/sunucu.py — Python HTTP server. Writes the port to zil-port.txt. Generates ses-manifest.json and mp3-manifest.json.
zunucu/handler.py — API route handlers (GET/POST). Manages all /api/ endpoints.
zunucu/ezan.py — Fetches prayer times via the Diyanet → diyanethaber.com.tr → Aladhan API chain. Haberturk/NTV as backup sources.
anfi2/anfi2.ino — Arduino Uno code. 9600 baud. Relay(D7), red LED(D12/150Ω), green LED(D11/100Ω), button(D4), RF×4(D2/D3/D5/D6).
zilsesleri/ — MP3 sound files. IstiklalMarsi.mp3, İstiklal.mp3, and other bell/music files.
anons/ — Announcement sound files (teacher/student/assembly/last-bell announcements).
zil-port.txt — Contains the server port (e.g. 8765). The HTML reads the port from this file.
zil-baslat.bat — Windows startup script. Launches the Python server and opens the browser.
arduino-usb-fix.bat — Permanently fixes Arduino USB connection issues. Run once as administrator. Disables USB Selective Suspend (Windows will no longer sleep USB devices), disables USB hub power management, and refreshes the USB enumeration service.
🌐 API Endpoints (sunucu.py / handler.py)
GET
/ses-manifest.json — List of sound files in the zilsesleri/ folder
/mp3-manifest.json — MP3 folder and file structure
/api/prayer-times?ilce=&il=&kaynak= — Fetch prayer times (Diyanet/haberturk/ntv)
/api/remote-poll — Get the pending remote command (mars/zil/stop/stop)
/api/blacklist — Blacklisted MP3 files
/api/ntp-check — System clock NTP sync check
/api/announcement-config — Announcement sound file settings (GET)
/api/bell-sound-config — Bell sound file selections (GET) — returns which mp3 is used for each SND_DEFS key; empty = the zil.mp3 default
/api/app-settings — Server-side settings backup (GET) — returns the whole zil-ayarlar.json as {ok, settings}, read by init() on startup
POST
/api/kumanda — Send a remote command {cmd: 'anthem'|'bell'|'stop'|...}
/api/announcement-config — Save announcement settings
/api/bell-sound-config — Save bell sound selections (called by persistSndToServer and bellSoundConfigSave)
/api/sound-upload — Takes a sound file as base64 and writes it to the zilsesleri/ folder (called by persistSndToServer)
/api/app-settings — Save one whitelisted setting {key, value} to zil-ayarlar.json (called by _serverSaveSetting — zilSistemiV10, zilAccordionView, zilOkulBilgi, zilAktivPlan)
/api/move-to-temp — Move an MP3 file to the temp folder (blacklist)
/api/restore-from-temp — Restore an MP3 from the temp folder
/api/blacklist — Add/remove from the blacklist {action:'add'|'remove', name}
/api/exit — Shut down the server
/api/shutdown — Shut down Windows
🔌 Serial Port Commands (Arduino Uno — 9600 baud)
▶ HTML → Arduino (sent)
ANFI_AC — Close the relay → 220V flows → amplifier turns on
ANFI_KAP — Open the relay → 220V cut → amplifier turns off
DURUM — Query the current amplifier state
◀ Arduino → HTML (received — handled by _ampMessageHandle)
OK:ANFI_ACILDI — Amplifier-on confirmation → _ampStatus=true, green LED
OK:ANFI_KAPATILDI — Amplifier-off confirmation → _ampStatus=false, red LED
DURUM:ACIK / DURUM:KAPALI — Query response
BUTON:MANUEL_TETIKLEME — D4 physical button pressed (INPUT_PULLUP, debounced)
MARS:TETIKLEME — RF CH1/A (D2) → manualPlay('anthem') — National Anthem
ZIL:TETIKLEME — RF CH2/B (D3) → manualPlay('bell') — Ring bell
ANFI:TOGGLE — RF CH3/C (D5) → ampToggle()
DUR:TETIKLEME — RF CH4/D (D6) → stopAll()
⚡ Key JS Functions
▸ Scheduler & Bell
tick() — Main loop, every second. Bell triggering, plan checks, quiet mode, and prayer-time checks happen here.
checkBells(ts,di,sched,fromSafetyTimer) — Decides whether a bell should ring. Triggers via fire().
fire(key,fn,label,time,sndKey) — Triggers a bell. Prevents re-triggering with _fireTs.
bellRing(normalKey,anonsKey,cb,dersNum) — Plays the bell + announcement chain. MP3 mode or normal sound.
manualPlay(key) — Manual sound playback. type: 'anthem','bell','tribute','ikaz','siren','anons' etc.
stopAll() — Stops all sounds. Audio.pause + clears the queue.
playChain(keys,cb) — Plays a list of sounds in order, calls cb when done.
▸ Schedule & Plan
buildDayTabs() — Rebuilds the week-tabs UI.
rebuildAllSchedules() — Recalculates the bell schedule for all 7 days.
renderTable(di) — Displays the bell table for day di.
buildSchedule(di) — Generates the day schedule for Plan A.
buildSchedulePlanB(di) — Generates the day schedule for Plan B.
buildSchedulePlanC(di) — Generates the group-based block-lesson schedule for Plan C. Processes the _planCSettings.gruplar array in order: each group consists of a type (block|single), lesson count, duration, and the break that follows. Lessons merge within a block group, with no bell in between.
_planForDaySelect(plan) — Called from the A/B/C button on a day tab. Saves instantly.
switchBellPlan(plan,fromTakvim) — Global plan change (settings radio buttons).
wholeWeekResetToDefault() — Bound to the ↺ Reset button on the tab bar. Sets all 7 days to Plan A: daySettings/rowStates revert to default, _dayPlans is set to 'A' for every day and saved to localStorage, _updatePlanCardUI('A') is called. It previously only reset the times but not _dayPlans (days with Plan B/C selected didn't revert to A) — this was fixed.
resetScheduleTimes() — Was bound to the old toolbar ↺ Reset button; recalculated the active day's times from buildSchedule. That button was removed; its function was merged into wholeWeekResetToDefault(). The function remains in the code but has no button in the UI.
saveDaySettings() — Saves Plan A day settings.
savePlanB() / loadPlanB() — Save/load Plan B settings.
savePlanC() / loadPlanC() — Save/load Plan C settings.
applyAndRender() — Applies Plan A and refreshes the schedule.
planBCalendarCheck() — Checks the Plan B calendar, updates _dayPlans.
▸ Amplifier & Serial Port
ampToggle() — Toggles the amplifier state, sends ANFI_AC/ANFI_KAP.
ampUIUpdate() — Updates the sidebar icon, LED dot, port label, and settings panel.
ampAutoConnect() — Auto-connects with the saved VID/PID. Calls _ampRetryStart() on failure.
_ampRetryStart() — Starts a 10s×12 retry loop. Stops via _ampRetryStop() once connected.
ampPortConnect() — Opens the requestPort() dialog, the user picks a port, VID/PID is saved.
_ampMessageHandle(msg) — Processes lines coming from the Arduino. All RF and button messages are handled here.
_ampReaderStart() — Starts the Web Serial read loop (TextDecoderStream).
_ampSerialSend(komut) — Writes a command to the serial port. Attempts to auto-reconnect if the port is disconnected.
▸ MP3 & Sound
playSnd(key,cb) — Plays a defined sound key (from SND_DEFS). Normalizes it with the Web Audio API.
playMp3Bell(cb,isTenefusCikis,zilType) — Picks and plays a song in MP3 bell mode.
_bellPlayerPlayOne() — Plays a single track in MP3 player mode.
playRepeat(key) / playRepeatNext() — Repeated sound playback (warning/siren).
vuUpdate(active,label,vol) — Updates the VU meter animation.
▸ Prayer Times & Quiet Mode
prayerConflictCheck(bellTimeStr) — Checks whether the bell time conflicts with a prayer time.
prayerAutoFetch() — Automatic daily prayer-time fetch. Triggered on the first tick in the morning.
isQuietModeActive() — Returns true if quiet mode is active. Checked by tick() every second.
▸ UI Helpers
addLog(ikon,msg) — Adds a line to the activity log.
switchTab(tab) — Main tab switch (schedule/settings/log).
switchSettingsTab(tab) — Settings sub-tab switch.
togglePin(panelId,idx) — Pins/unpins a panel (sticky).
buildSndPanel() — Builds the sound files panel.
buildMp3BellMatrix() — Builds the MP3 bell matrix (which MP3 for which bell).

🔧 Arduino Hardware Map (Uno)
D2 — RF CH1/A → MARS:TETIKLEME (INPUT_PULLUP, momentary mode, debounced)
D3 — RF CH2/B → ZIL:TETIKLEME (INPUT_PULLUP, momentary mode, debounced)
D4 — Manual button → BUTON:MANUEL_TETIKLEME (INPUT_PULLUP, to GND, debounced)
D5 — RF CH3/C → ANFI:TOGGLE (INPUT_PULLUP, momentary mode, debounced)
D6 — RF CH4/D → DUR:TETIKLEME (INPUT_PULLUP, momentary mode, debounced)
D7 — 30A relay IN (220V amplifier control — may be a LOW-active relay, LOW-active handling included)
D11 — Green LED anode (100Ω resistor — amplifier on)
D12 — Red LED anode (150Ω resistor — amplifier off)
RF receiver: 433MHz, 4-channel, momentary mode. CH×A(NO)→pin, CH×B(COM)→GND. Internal pull-up — no external resistor needed. Supply: 5-30V.
